# 辩论社网站

这是一个单页响应式网站和配套报名服务：页面为原生 HTML、内联 CSS 与 JavaScript；报名由 Node.js + Express 接收，并保存在 SQLite 数据库中。

## 本地运行

需要 Node.js 20 或更高版本。克隆仓库后在项目目录运行：

```sh
npm install
npm start
```

打开 <http://localhost:3000>。服务首次启动时会自动创建 `data/signups.sqlite`；设置 `PORT` 可更改监听端口，设置 `DATA_DIR` 可指定数据库目录。

运行测试：

```sh
npm test
```

## 部署说明

GitHub 仓库或 GitHub Pages 只能存放/托管静态文件，不能执行本项目的 Express API。请将整个项目部署到支持 Node.js 20+ 的服务器或应用平台，并为 `DATA_DIR` 配置可持久化磁盘路径。需要让网页和 `/api/signups` 处于同源 HTTPS 地址下；如果平台使用反向代理，请按平台要求配置代理与 HTTPS。

数据库文件包含申请者的姓名、年级、电话和自我介绍。`data/` 已加入 `.gitignore`，不要将数据库文件、备份或真实报名信息提交到 Git。上线前必须由社团确认数据访问人员、保存期限、删除流程及隐私告知内容；项目不提供公开查询或管理报名资料的接口。

报名接口会限制请求频率、验证字段并限制请求体大小。默认同一客户端每 15 分钟最多提交 5 次。
